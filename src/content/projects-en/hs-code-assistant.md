HS Code Assistant uses information such as a product's name, specifications, and intended use to suggest possible tariff classification codes and support the final decision made by trade professionals.

Trade classification depends heavily on specialist knowledge and experience. AI-assisted first-pass classification can reduce the practical workload while preserving human review. The project is a working exploration of the intersection between AI and international trade.
