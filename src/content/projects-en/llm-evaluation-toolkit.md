A toolkit for continuously evaluating applications built with large language models.

## Areas covered

- Golden dataset design and construction
- Automated evaluation with LLM-as-a-Judge
- RAG evaluation for retrieval and answer quality
- Hallucination detection
- Regression testing for quality degradation
- Agent evaluation

As LLM applications become more common, maintaining quality after launch becomes increasingly important. This toolkit explores the practices and infrastructure needed to make that quality measurable.
