# LLMO Baseline — 2026-09-16

## Status

This document records the first reproducible public-search baseline collected before publishing the first buyer-intent page. It is evidence of the experiment setup, not evidence that TechVit already ranks in ChatGPT, Gemini, or Perplexity.

## Scope and limitation

A public web search was run for the five P0 buyer-intent themes. Search results are used here to identify the content and entities currently occupying these intents. Direct ChatGPT / Gemini / Perplexity prompt-panel measurements must be recorded separately when run in those products or through an authorized measurement integration.

No claim of LLM citation share is made from ordinary web-search results.

## Observed competitive pages

### Query theme: AI業務改善 / 生成AI導入支援会社の選び方

Observed pages included:

- GXO — 生成AI導入支援会社の選び方 / 比較軸
- SnapBuild — AI・システム開発会社の選び方
- AI企業名鑑 — AI導入コンサルティングの選び方
- The Company Journal — AI導入支援会社比較

Recurring decision criteria across visible pages included implementation ability, transition from PoC to production, business understanding, security/data governance, pricing transparency, and the scope of support.

### Query theme: 小規模PoCから対応するAI開発会社

Observed pages included:

- Wildcard — 生成AI PoCからMVP開発
- wellnare — small PoC positioning
- Gugen AX — PoC development package

This indicates that concrete PoC scope, duration, price where publishable, and the decision after the PoC are strong information needs for this intent.

### Query theme: RAG導入支援会社の比較

Observed page:

- Radineer — RAG構築・AI社内検索の会社比較

The visible result is structured around company comparison, cost, track record, data sources, selection criteria, implementation flow, examples, and FAQ.

### Query theme: AI導入コンサルとAI開発会社の違い

Observed pages included:

- ルートチーム — AI受託開発とAI導入コンサルの違い
- NEXA — AI導入コンサル / AI顧問 / AI開発会社 / ITベンダー
- CS Plus — AIコンサルティングとAIシステム開発の違い
- ノーコードソリューションズ — AIコンサルとAI開発会社の使い分け
- 社外AI推進室 — AIコンサル / AI開発会社 / 業務代行

The recurring distinction is between deciding what to improve and building an operational system. Several pages explicitly note that real providers can span both categories, so deliverables and scope are more useful than company labels.

## TechVit baseline observation

In this public-search sample, TechVit was not observed among the returned pages for the five P0 intent themes.

This is the useful starting condition: there is no basis yet to claim visibility. The experiment can now measure whether publishing answer-ready, evidence-backed pages changes discoverability over time.

## Evidence policy

Future updates to this document must separate:

1. Public web-search visibility
2. Direct AI-engine answer measurements
3. TechVit site analytics
4. Qualified inquiries / conversions

Never translate one measurement type into another. For example, a Google result is not an LLM citation, and an LLM mention is not a lead.
